# Swasthya Connect - Frontend Application

A high-performance, premium React application designed for the best possible user experience in Nepalese healthcare.

## 🌟 Visual & UX Features

- **Dynamic Dashboards**: Role-specific interfaces for Patients, Doctors, and Pharmacies with real-time stat updates.
- **Unified Store**: Premium e-commerce experience for medicine shopping with advanced filtering.
- **Smart Components**: 
    - **Notification Bell**: Real-time unread count and dropdown for platform-wide alerts.
    - **Live Chat Widget**: High-tier chat experience with typing indicators and attachments.
    - **Distance Tracker**: Real-time distance calculation to nearby pharmacies.

## 🛠️ Technical Implementation

- **Framework**: Vite + React for ultra-fast performance.
- **State Management**: Optimized Context API for Auth, Profile, and Notifications.
- **Real-time**: Persistent Socket.IO connection across the app.
- **Telehealth**: Integrated Agora RTC for seamless video/audio calls.
- **Styling**: Premium UI using Tailwind CSS and Radix UI primitives.

---

## 🚀 Page Guide

- `/store`: The central medicine hub.
- `/dashboard`: Personal patient health and order tracker.
- `/doctor/dashboard`: Practice management for medical professionals.
- `/pharmacy-dashboard`: Inventory and prescription verification portal.
- `/admin/dashboard`: Platform control center.

---

## ⚙️ Development Setup

1. Run `npm install`.
2. Configure `.env` with `VITE_API_URL` and `VITE_AGORA_APP_ID`.
3. Start development server: `npm run dev`.
